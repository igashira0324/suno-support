Layout Optimization & User Experience Guide

Layout 1. 結果表示の優先配置

生成された楽曲は、左カラムの最上部に即座に表示されるようになりました。これにより、Lyrics（歌詞）の編集を続けながら、生成結果をすぐに確認・再生できます。

graph TD A[UI Layout] --> B[Left Column] A --> C[Right Sidebar] B --> D[Result Section (New!)] B --> E[Lyrics Editor] C --> F[Settings] C --> G[Image Analysis]

UX 2. 生成結果の永続化と自動スクロール

永続化 (Persistence) 新しく生成しても以前の結果は消えません。履歴としてリストの上部に追加されます。
自動スクロール 生成完了時に、自動的に結果セクションへスムーズにスクロールします。

Stability 3. 安定性の向上

  • Gemini 429 回避: タイトル自動生成を一時停止し、APIレート制限によるエラーを防止しました。
  • Audio互換性: MP3出力への対応を強化し、プレイヤーの再生安定性を向上させました。
