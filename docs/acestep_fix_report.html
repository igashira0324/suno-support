ACE-Step Stability Fix Report

STATUS 修正完了 / Optimized

ACE-Step の音楽生成プロセスにおける通信エラーとレスポンス解析の不備を修正しました。これにより、生成された音声が正しくUIに表示され、再生可能になります。

修正のポイント

  • モデルの同期: 起動スクリプトに合わせ acestep-v15-turbo をデフォルトに設定。
  • URL 正規化: 相対パスを絶対 URL に自動変換し、再生エラーを防止。
  • 堅牢なパース: JSON 文字列/配列の両方のレスポンス形式に対応。

システムシーケンス図

sequenceDiagram participant UI as Frontend participant BE as Backend (FastAPI) participant AS as ACE-Step API UI->>BE: 生成リクエスト (Turboモデル) BE->>AS: タスク発行 Note over AS: 音楽生成中... loop ステータス確認 UI->>BE: 進捗確認 BE->>AS: query_result AS-->>BE: 完了 (JSON配列/文字列) end BE->>BE: URL正規化 (http://127.0.0.1:8101/...) BE-->>UI: 最終結果 (再生可能URL) UI-->>UI: プレイヤー表示
