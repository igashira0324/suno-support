🐛 問題の概要

発生していた問題

4つのタブ（Prompt Gen / YuE Generate / ACE-Step 1.5 / MV Support）を切り替えると、 各タブで入力・設定した内容がすべてリセットされてしまう。

例：「Prompt Gen」でテキストを入力 → 「MV Support」に切り替え → 「Prompt Gen」に戻ると入力が消えている。

🔍 原因分析

条件付きレンダリングによるアンマウント

App.tsx の main 要素内で、三項演算子（条件付きレンダリング）を使用してタブを切り替えていました。 

// ❌ 修正前: 条件付きレンダリング（三項演算子）
{activeTab === 'prompt' ? (
    <InputSection ... />
) : activeTab === 'yue' ? (
    <YuEGenerationTab />    ← 非アクティブ時にアンマウント
) : activeTab === 'ace' ? (
    <AceStepTab />          ← 非アクティブ時にアンマウント
) : (
    <MvProductionTab />     ← 非アクティブ時にアンマウント
)}

この方式では、非アクティブなタブのコンポーネントがDOMから完全に削除（アンマウント）され、 再選択時に新規作成（マウント）されるため、useStateで保持していた内部状態がすべて失われます。

✅ 修正内容

修正前

条件付きレンダリング（三項演算子）

  • アクティブなタブのみDOMに存在
  • 非アクティブなタブはアンマウント
  • 状態がリセットされる
修正後

CSS display: none 切り替え

  • 全タブが常にDOMに存在
  • 非アクティブなタブは非表示
  • 状態が保持される ✨

修正後のコード

// ✅ 修正後: CSS display:none で切り替え
<div style={{ display: activeTab === 'prompt' ? 'block' : 'none' }}>
    <InputSection ... />
</div>
<div style={{ display: activeTab === 'yue' ? 'block' : 'none' }}>
    <YuEGenerationTab />     ← 常にDOMに存在！
</div>
<div style={{ display: activeTab === 'ace' ? 'block' : 'none' }}>
    <AceStepTab />           ← 常にDOMに存在！
</div>
<div style={{ display: activeTab === 'mv' ? 'block' : 'none' }}>
    <MvProductionTab />      ← 常にDOMに存在！
</div>
