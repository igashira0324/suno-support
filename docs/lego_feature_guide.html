ACE-Step v1.5 New Feature

Legoモード (歌付与機能)
ビジュアル解説・操作ガイド

アップロードした伴奏（BGM）や楽器音源に対し、歌詞を指定して歌声（Vocal）や別トラックをブレンドして生成する「Lego」機能のワークフローです。

オーディオ重ね合わせイメージ

Lego（マルチトラック生成）は、元の音源の位相やリズムを保ったまま、AIが歌詞のメロディと歌声トラックを自然に合成する高度なインペインティング技術です。

🚀 ご利用手順

01

タスクモードにLegoを選択

右側の「Task Mode」から lego を選択します。自動的にモデル設定が Base に切り替わります（LegoはBaseモデルのみ対応）。

02

既存の楽器・BGMをアップロード

新設された Source Audio エリアにて、歌をのせたい楽器ファイル（MP3/WAVなど）をドラッグ＆ドロップまたは選択して指定します。

03

歌詞を入力し生成

歌わせたい歌詞（[Verse 1], [Chorus] 等のタグ含む）を入力し、プロンプトで歌声のスタイル（女性ボーカル、感情豊かなど）を指定し、「Initialize Generation」を押下します。

💻 Windows アプリ起動用バッチファイル

Windows環境ですぐにシステム（FastAPIバックエンド、Viteフロントエンド、ACE-Step APIサーバー）を立ち上げられるよう、プロジェクトルートに専用の起動用バッチファイル run_acestep_lego_app.bat を同梱しています。

使い方:

  1. プロジェクトのルートディレクトリを開きます。
  2. run_acestep_lego_app.bat をダブルクリックします。
  3. 自動的に必要なサービス（バックエンド、ACE-Step、Vite）が同時起動し、ブラウザでアプリが立ち上がります。
