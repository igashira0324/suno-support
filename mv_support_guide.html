MV Production Support

URL経由の自動オーディオ抽出・分離機能

✨ 新機能のハイライト

ファイルアップロードの必要はありません。お気に入りの動画や楽曲のURLを貼り付けるだけで、高品質なボーカル分離が数クリックで完了します。

📺 多彩なソース対応

YouTube (標準/ショート), TikTok, Suno.ai, SoundCloud, その他直リンク等に対応。

⚡ バックグラウンド処理

ダウンロードと分離（BS-RoFormer）を非同期で実行。UIを止めることなく作業を継続可能です。

🎨 統一されたUI

ACE-STEPタブと一貫性のあるデザイン。直感的な操作が可能です。

🔄 処理フロー図 (UML)

graph LR Start([URL入力]) --> Download(自動ダウンロード) Download --> Separate{ボーカル分離開始} Separate --> Process[BS-RoFormer GPU処理] Process --> Result([Vocals / Instrumental]) style Start fill:#6366f1,color:#fff style Result fill:#a855f7,color:#fff

🚀 使いかた

STEP 1

URLのコピー

ブラウザから対象となる楽曲のURLをコピーします。

STEP 2

インポート

「MV Support」タブの Import from URL 欄に貼り付け、Import をクリックします。

STEP 3

待機と編集

Downloading → Separating の表示が終わるのを待ちます。完了後、自動的に解析が行われ、トリミングやダウンロードが可能になります。

🛠️ 開発者向けチップス

APIを直接叩く場合は POST /separate-url を使用します。JSON形式で {"url": "..."} を送信してください。

同梱の test_url_import.bat を実行することで、コマンドラインから即座に動作を確認できます。
