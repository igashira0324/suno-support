ACE-Step 命名規則カスタマイズ

📝概要

生成される音楽ファイルのファイル名を、入力された「Theme（テーマ）」に基づいて自動設定する機能を実装しました。 同じテーマの曲を複数生成した場合、自動的に連番（_1, _2...）が付与され、既存のファイルが上書きされるのを防ぎます。

🔄処理フロー

graph TD A[Frontend: Theme入力] --> B[API POST Request] B --> C{Backend: Theme有無チェック} C -- 有り --> D[サニタイズ処理
記号の除去] C -- 無し --> E[デフォルト命名
UUID] D --> F{既存ファイル確認} F -- 重複あり --> G[連番付与 _1, _2...] F -- 重複なし --> H[保存実行] G --> H E --> H

🛠️主な変更点

  • Frontend: AceStepTab.tsx でリクエストに theme フィールドを追加。
  • Backend API: api_server.py でリクエストモデルを拡張し、生成パラメータにテーマを渡すよう変更。
  • Inference Logic: inference.py に _sanitize_filename 関数と重複回避ロジックを実装。

🚀確認方法

1. ACE-Stepタブを開きます。
2. 「Theme / テーマ」入力欄に好きなタイトルを入力します。
3. 生成を実行すると、outputs\acestep フォルダにテーマ名のファイルが作成されます。
